SMASH COURT — BADMINTON TOURNAMENT WEBSITE

HOW TO USE
1. Extract the ZIP file to a folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Pool A is Teams 1–4; Pool B is Teams 5–8. Team pairings remain unchanged.
4. Enter scores for the 6 matches in each pool, in the format 21-18. Only same-pool matches count toward pool standings.
5. The first-place team in each pool meets in Qualifier 1. The second-place teams meet in Qualifier 2.
6. Qualifier 1 winner goes directly to the Grand Final. Qualifier 1 loser plays Qualifier 2 winner in the Eliminator. The Eliminator winner joins the Qualifier 1 winner in the Grand Final.
7. Scores, winners, pool points, score differences, and the champion update automatically. Scores are saved in the browser on that device.
8. Use Export results to download a CSV, or Reset all scores to clear the tournament.

SCORING AND TIE-BREAKS
- Win = 2 points; loss = 0 points.
- Pool ranking: points, then score difference, then wins, then original team number.
- Match score input: one field such as 21-18; difference is calculated automatically.
- There are 12 pool matches and 4 playoff matches.

IMPORTANT
- The randomly shuffled team pairings and original fixture ordering are preserved. The website uses the original fixture order for matches within each pool; cross-pool fixtures are excluded from pool play.
- The hero photo and Google Fonts load from the internet. The rest of the site runs locally.
- This is a static website; to share live scores across devices, host it and add a shared database/backend.

DEPLOY
- This is a static site: upload the folder contents (index.html at the root) to Netlify Drop, Vercel, GitHub Pages, Cloudflare Pages, or any web host.
- No build step is needed.
